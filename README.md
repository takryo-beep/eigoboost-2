# EigoBoost 簡易版（12時間に1問）

元サイトのコミット `60d13b0` の画面を基にした独立した修正版です。前回のRedis版を使う必要はありません。このフォルダーの内容だけを別のプロジェクト、または元プロジェクトへ反映します。ローカル作成のみで、GitHubへの変更やデプロイはしていません。

## 使い方と変更点

- 1問の採点に成功した時刻から12時間後に、次の1問を利用できます。例: 10:30に成功→22:30に再開。午前0時のリセットではありません。
- APIエラーや採点失敗では1問を消費しません。429のときは画面に待機メッセージを出し、連続した自動再試行はしません。
- 出題した1問はブラウザーに保存し、再読み込み・設定変更・出題ボタンの連打では作り直しません。レベル・ジャンルの変更は次の問題作成時に適用されます。
- 答案の下書きと採点結果も保存します。待機中に再読み込みしても前の結果を復習できます。
- 12時間経過で画面の制限を自動解除します。読み上げはブラウザー標準機能を使います。
- 外部データベース、生徒ログイン、待ち行列、常時稼働ワーカーは不要です。

## 設定

元サイトと同じVercelのNode API形式です。`index.html` と `api/grade.js` に加え、このフォルダーの `package.json` と `vercel.json` を使用してください。環境変数に以下を登録します。APIキーはHTMLへ書きません。

```text
GEMINI_API_KEY=ご自身のAPIキー
GEMINI_TEXT_MODEL=gemini-3.5-flash-lite
```

Gemini 3.5 Flash-Liteを既定モデルにしています。Googleの公式料金表では無料枠があり、既存のGemini接続を活用できます。利用できるモデルとRPM・RPD・TPMはAI Studioで確認してください。以前の画面の15 RPM・500 RPDが、このモデルにもそのまま適用されるとは限りません。2.5 Flash-Liteが利用可能でその枠を確認できる場合は、環境変数を `gemini-2.5-flash-lite` に変えるだけで切り替えられます。

- [公式料金表](https://ai.google.dev/gemini-api/docs/pricing)
- [Gemini 3.5 Flash-Lite](https://ai.google.dev/gemini-api/docs/models/gemini-3.5-flash-lite)
- [実際の上限の確認方法](https://ai.google.dev/gemini-api/docs/rate-limits)

## 簡易版の制約

回数制限は同じサイト・同じブラウザーの保存領域（localStorage）に基づきます。別端末、別ブラウザー、プライベートモード、保存データの削除や端末時計の変更をまたぐ厳密な生徒別制限ではありません。APIを直接呼ぶことも制限できません。厳密な本人別管理にはログインと共有保存先が必要です。

12時間制限で1日あたりの利用は減らせますが、35人の一斉利用による分当たりの制限は残ります。問題生成と採点は別のAPI呼び出しです。15 RPMの場合は、出題・提出を時間差で行ってください。例として1分あたり10人程度ずつに分けても、同じ時間の出題・採点・他サービス利用・TPMによっては429になる場合があります。

無料枠の容量や採点品質は保証できません。実際のAPIにはまだ接続していないため、利用前に代表的な答案で確認してください。Geminiの無料枠では送信内容がサービス改善に使われる旨が公式料金表に記載されているので、氏名などを答案に入れない運用にします。

履歴は元サイトと同じくこのブラウザーに保存されます。共用端末では履歴・下書きの取り扱いに注意してください。ブラウザーの読み上げは端末により音声・対応状況が異なります。

## 検証

Node.js 22以上で、このフォルダー内で `node --test` を実行できます。テストは外部APIを呼びません。Vercel環境での画面操作と実API接続、クラス同時利用は別途確認してください。
